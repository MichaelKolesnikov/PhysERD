DBML quick reference

DBML (Database Markup Language) describes a database structure. The diagram follows the text as you type.

Tables and columns

Table schema.table_name as alias [headercolor: #3498db, note: '...'] {

  email varchar(255) [not null, unique, note: 'Login']
  created_at timestamp [default: `now()`]

}

Indexes

Table bookings {
  id integer
  country varchar
  booking_date date

  indexes {
    (id, country) [pk]                          // composite primary key
    booking_date [name: 'date_index', type: hash]
    (country, booking_date) [unique]
    `lower(country)`                            // expression
  }
}

Enums

Enum job_status {
  created [note: 'Waiting to be processed']
  running
  "with space"
}

Table jobs {
  status job_status
}
